# 0.2 验证与边界

环境：macOS、Node.js 24；CLI 编译目标 Node.js 22，Action 为 Node.js 24。测试全部在后台进行，使用独立无头 Chromium 和临时用户配置，不打开或操控用户已有浏览器。

0.2.0 最终验证：类型检查与构建通过；34 项单元 / 集成测试和 9 项端到端测试全部通过，共 43 项，零失败、零跳过。端到端测试包含构建后的原生 Chrome 扩展、独立 CLI 工作台和 GitHub Action。

## 功能证据

| 要求 | 验证范围 |
| --- | --- |
| Chrome 标签页分组 | 无头真实 Chromium 加载构建后的扩展，原生 tabs / tabGroups 分组、搜索、手动分类、撤销 |
| Chrome 取消、继续和偏好 | 延迟注入后通过真实面板停止与继续，验证分类恢复；保存阈值和域名排除后重新加载检查 |
| 工作台 GitHub 全流程 | 浏览器点击生成演示、搜索筛选、修正、备注转义、导出 HTML、刷新历史 |
| 工作台飞书全流程 | 通过真实浏览器操作字段检查、计划、确认、回填、回执和撤销；飞书 API 由契约样例代替 |
| 打包程序运行 | 启动构建后的独立 `dist/jev.mjs serve`，通过浏览器完成离线工具箱生成 |
| 数据与恢复 | 分类缓存失效条件、失败批次重试、人工覆盖优先、工作台重启恢复与中断标记、飞书筛选分页、排除与修正、回填冲突 / 幂等 / 归属记录 / 撤销 |
| 工作台访问边界 | 无会话、跨站 Origin、伪造 Host、无效输入、重叠任务被拒绝；密钥不出现在状态或历史文件 |
| 页面可用性 | 桌面与窄屏布局检查，无横向溢出，交互无未捕获页面错误，导出中的不可信文本被转义 |

当前完整验证命令为 `npm run verify:all`，详细用例在 `tests/` 和 `tests/e2e/`。构建产物与两个 ZIP 由 `npm run package` 逐文件校验，并生成 SHA-256 校验值。

```bash
node dist/jev.mjs demo
npm run package
```

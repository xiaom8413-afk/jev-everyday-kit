# Tab Sort · Chrome / Edge 标签页整理

## 安装

1. 解压独立扩展 ZIP，或在完整包中找到 `dist/chrome/`。从源码使用先运行 `npm ci`、`npm run build`。
2. 自己方便时打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启开发者模式。
3. 选择“加载已解压的扩展程序”，选择含有 `manifest.json` 的目录。
4. 点击工具栏 Jev 图标。先试离线样例，再填 TypeSafe API Key。

扩展不会自动打开新窗口或网页。密钥在 `chrome.storage.session`，关闭浏览器 / 重载扩展后需重新输入。与本地工作台的密钥互不共享。

## 分析与整理

- 默认最多分析当前窗口 300 个符合条件的页面，可在偏好中改为 15–500。
- 固定、无痕、已有分组、浏览器内部页及排除域名自动跳过。
- 每批 15 页，进度持续保存。可以停止并继续；后台被浏览器终止后，再打开扩展也能继续尚未完成的部分。
- 长任务接近浏览器的单事件时间限制时主动暂停，点击继续即可。不会靠无限保活占用浏览器。
- 只想使用已经完成的部分时，点击“采用已完成结果”。剩余页面保持原样。

预览中可以搜索标题 / 域名、选择或取消可见页面，逐个改变类别。模型低把握项默认不参与分组；手动选择明确类别后可以参与，并标记“手动”。演示数据不能应用到真实页面。

点击“应用选中分组”创建原生标签组。应用前再次检查页面地址、标题、窗口与分组状态；已经变化的页面会跳过。

## 偏好

- 模型名称：默认 `jev-latest`，可指定账号可用的版本。
- 阈值：60%、75%、85%；更高时更多页面留给人工确认。
- 数量上限：15–500 页。
- 分组前缀：默认 `Jev`，例如改为 `Focus`。
- 自动折叠：创建分组后是否收起。
- 排除域名：每行一个纯域名，包含其子域名，不填写 `https://` 或路径。

偏好保存在浏览器本地，下次分析生效，不会同步 Google 账号。已生成计划继续使用当时的设置，避免分析中途更换规则。

## 撤销

同一窗口保留一轮撤销记录。点击“撤销分组”恢复未分组状态；如果窗口顺序与应用后完全一致，扩展还会尝试恢复之前的顺序。用户调整过的窗口保留当前顺序。

分组成员或页面地址被改过时，该组保留，避免打乱后续工作。暂时无法撤销的组也保留撤销记录，可以重试。点击“保留分组”结束这轮撤销记录，再整理下一批。

浏览器重启会清空会话中的密钥、计划和撤销记录；已经创建的原生标签组由浏览器管理。

## 数据与权限

仅把页面标题与域名发送给 TypeSafe。完整 URL 只在扩展会话中用于检测变化，不发送路径、查询参数、片段或 URL 凭据。不读取页面正文、表单或历史，不关闭页面。

权限只有 `tabs`、`tabGroups`、`storage` 和 Jev 官方 API 域名。没有网页内容脚本。

401 / 403 请检查官方 TypeSafe Key 和模型权限；429 / 超时可稍后继续，已完成的分批结果会保留。这个 Key 不是 OpenRouter Key。

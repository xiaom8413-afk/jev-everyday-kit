让窗口重新清爽。

扩展在当前窗口分析标签页标题和域名。你可以搜索、取消选择或调整分类，再创建原生标签组。

分析支持进度、中断恢复和取消；分组支持撤销。已有分组、固定和无痕标签默认跳过。

  1. 01

    找到扩展目录

    解压完整安装包，找到 dist/chrome/。从源码使用时先运行 npm run build。

  2. 02

    由你手动加载

    方便时进入 chrome://extensions 或 edge://extensions，开启开发者模式，加载已解压的扩展。

  3. 03

    从样例开始

    点击工具栏的 Jev 图标。先试样例，再填写会话 API Key，分析自己的窗口。

操作台不会自动打开浏览器或安装扩展。工作台和扩展分别保存各自的会话密钥。
